### Known divergences between installed material and the fixed stack (engineers follow the decisions, not the skill)

1. `monad` SKILL.md says "Foundry v1.8+ with `--execution-network monad`" (twice). That flag is stale. The Monad docs Foundry page (https://docs.monad.xyz/tooling-and-infra/toolkits/foundry.md) and the installed forge 1.8.3 (`forge test --help` lists `--network` with possible values `ethereum, optimism, tempo, monad`) use `network = "monad"` in `foundry.toml` or `--network monad`. D2 in `05-synthesis.md` is correct.
2. `monad` SKILL.md step "Create `.env` with private key and RPC URL" contradicts D15 (deployment from a laptop with a Foundry keystore, never from CI). Engineers must use `forge script --account <keystore> --sender <addr>` and must never create a `.env` holding a key. The PM should repeat this in the contracts handoff.
3. `monad` SKILL.md and `monad-docs` are generic Monad guidance; on conflict with a live probe, the live probe wins (C10, C11 in the synthesis).
4. `monad-docs` exposes `submit_feedback`, which posts to the Monad docs team. It is an outward-facing write. No agent should call it. A project `permissions.deny` entry for `mcp__monad-docs__submit_feedback` is recommended (see Needs the user); this agent may not edit settings files.
5. `openzeppelin-solidity` generates against the latest OpenZeppelin release, not necessarily 5.6.1. Engineers must pin `lib/openzeppelin-contracts` to v5.6.1 and diff the generated shape against that source, never paste the output blindly.
6. Solidity 0.8.31 sits in the range 0.8.28 to 0.8.33 affected by a high-severity IR-pipeline bug (wrong storage domain when clearing a persistent and a transient variable of the same type with `delete`). Source: https://soliditylang.org/blog/2026/02/18/solidity-0.8.34-release-announcement/ (read 2026-10-19). It triggers only with `--via-ir` and `delete` on a transient state variable. The plan uses neither, so 0.8.31 stands. Engineers must not enable `via_ir` or use `transient` storage without moving to 0.8.34 or later. This finding came from the rejected Cyfrin skill and is worth putting in the contracts handoff.
